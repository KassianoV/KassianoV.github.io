# KassianoV.github.io

Portfólio pessoal de **Kassiano Vieira** — Desenvolvedor Front-End.

## Sobre

Site estático desenvolvido com HTML e CSS puro, apresentando minha trajetória, stack e projetos. Hospedado via GitHub Pages em [kassianv.github.io](https://kassianv.github.io).

## Stack

- HTML5 / CSS3
- Fontes: JetBrains Mono + Plus Jakarta Sans (Google Fonts)
- Deploy: GitHub Pages

## Como rodar localmente

Basta abrir o `index.html` diretamente no navegador — não há dependências ou build step.

## Deploy

O site é publicado automaticamente via **GitHub Pages** a partir da branch `main`.
